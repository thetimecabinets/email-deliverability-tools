# Email Deliverability Tools

A curated list of tools and guides for diagnosing and fixing email authentication issues (SPF, DKIM, DMARC).

---

## 🔧 Tools

### Email DNS Check
https://emaildnscheck.com

Free tool to diagnose SPF, DKIM and DMARC errors. Includes clear explanations and fixes for common email authentication problems.

## 🚀 Why this matters

Email authentication is essential for deliverability. Misconfigured DNS records can cause emails to fail, land in spam, or be rejected.

This repository helps developers and founders quickly debug and fix these issues.
